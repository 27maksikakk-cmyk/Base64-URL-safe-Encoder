# 🔐 Base64 URL-safe Encoder — кодируй безопасно для URL

> «URL-safe Base64 — без плюсов, без слешей, без проблем»

**Base64 URL-safe Encoder** — это набор консольных утилит для кодирования и декодирования данных в URL-safe Base64 (RFC 4648).  
В отличие от стандартного Base64, этот вариант использует символы `-` и `_` вместо `+` и `/`, а также не требует padding (`=`), что делает результат безопасным для использования в URL, именах файлов и параметрах запросов.

## 🚀 Особенности
- 🔢 Кодирование строк и файлов в URL-safe Base64.
- 📋 Автоматическое копирование результата в буфер обмена.
- 🔄 Декодирование URL-safe Base64 обратно в текст/файл.
- 📁 Поддержка ввода из файла, строки и STDIN.
- 📤 Экспорт результата в файл.
- 🎨 Цветной вывод в терминале.
- ⚡ Работа с большими файлами (потоковая обработка — где реализовано).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | `pyperclip` (опционально)            | `python base64_url.py`                  |
| Go         | стандартная библиотека               | `go run base64_url.go`                  |
| JavaScript | `clipboardy` (опционально)           | `node base64_url.js`                    |
| Java       | `java.awt` (встроенный)              | `javac base64_url.java && java base64_url` |
| C#         | `System.Windows.Forms` (для буфера)  | `dotnet run`                            |
| Rust       | `arboard`, `base64`                  | `cargo run`                             |
| Ruby       | `clipboard` (gem)                    | `ruby base64_url.rb`                    |
| PHP        | стандартная библиотека               | `php base64_url.php`                    |
